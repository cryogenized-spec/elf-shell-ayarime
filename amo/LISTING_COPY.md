## Full description
Step into Ayarime's cyber-elf workstation: a nostalgic, 1990s-OVA-inspired Firefox new-tab dashboard combined with an adaptive browser colour palette.

The new tab provides an integrated search and command palette, custom quick links, bilingual Memory Trace excerpts, original offline illustrated stories, local notes and saved workspaces. A built-in RSS/Atom reader follows only publications you choose. Optional browser APIs enable tab, history and bookmark tools after you grant permission. Nothing in this package requires an account, paid subscription or cloud sync.

Linux users may separately install a read-only Native Messaging companion to display available CPU/GPU temperatures, RAM usage, fan speeds and system load. The companion is optional, must be installed manually, and sends no measurements to the publisher. Missing sensors display N/A.

ELF//SHELL does not collect developer analytics or browsing history. Notes and saved workspace details are stored locally in your Firefox profile, not encrypted; be mindful of sensitive information before exporting them. The project is independent of Mozilla and OpenAI. The footer links to ChatGPT but does not embed or integrate its services.
