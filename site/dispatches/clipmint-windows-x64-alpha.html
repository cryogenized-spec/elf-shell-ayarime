I / THE ARRIVAL

One archive, two homes.

ClipMint was built to keep small things from disappearing: copied text, images, file references and the fragments of a working day. The Windows project carries that idea into a second environment without turning the Linux Mint application into a cross-platform compromise.

The editions live in separate repositories. Windows stores its clipboard history under %LOCALAPPDATA%\ClipMintWindows, does not migrate or read the Linux database, and has its own Windows capture, shortcut, packaging and signing code.

II / THE PACKAGE

One download, nothing to assemble.

The Windows alpha is delivered as a single portable ZIP containing ClipMint-Windows.exe, the Python/Qt runtime, approved crimson-and-gold branding, and FFmpeg for optional MP4 screen recording. The application needs no separate Python installation, FFmpeg download or PATH configuration. Extract the whole ZIP and run the executable from its folder.

The current package supports clipboard-history collections, search, pinned entries, screenshots and optional recording. Clipboard data is stored locally in plaintext by default; sensitive material should not be entrusted to this alpha.

III / THE PROVENANCE

A signature with clear limits.

The Windows GitHub Actions pipeline passed its unit, packaging and frozen-application smoke tests. Its executable bears a self-signed Authenticode development signature. The final ZIP also has a GitHub-signed build provenance attestation, verified by the workflow, which ties that package to its source and CI run.

These are useful integrity and provenance checks, not a claim of Microsoft-trusted publisher identity. Windows SmartScreen may still display an Unknown Publisher warning. The package is not code-signed with a commercially trusted certificate, and no production installer or automatic updater is included.

IV / THE NEXT MORNING

Now, put it on a real desk.

Physical Windows testing is planned next: clipboard behaviour between applications, close-to-tray operation, drag-and-drop, screenshots across different display scales, and actual screen recording. Until those checks pass, the honest label remains developer alpha.

There is a particular satisfaction in seeing a working idea take a second form. There is also value in knowing when not to call it finished.
