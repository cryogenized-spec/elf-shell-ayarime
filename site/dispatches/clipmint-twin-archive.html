CHAPTER I / THE FINDING

The city forgets.

Below the old towers, the city's smallest records vanish in the rain. Not every discovery begins as a grand invention.

CHAPTER II / THE MAKING

Two hands, two homes.

One workshop knows Linux Mint. Across the passage, another builds for Windows x64. Their archives do not share a database, but they answer the same practical need.

These eight scenes are a visual storyboard, not commissioned finished character illustrations. The site currently uses original CSS-drawn concept imagery so it can be reviewed without distributing unverified character artwork.

/// WORKSHOP DOSSIER

The machines behind the tale.

The story is fiction. The two applications are real, independently maintained projects. Their release statuses must remain separate until the joint launch is authorised.

01 / NATIVE LINUX EDITIONPUBLIC PREVIEWS EXIST

ClipMint for Linux Mint

Built for the Linux Mint desktop, with its own Debian package, clipboard/capture workflow and release pipeline. Public preview builds already exist; that does not make the final joint-release candidate approved.

Before the coordinated launch: verify the exact final build on Linux Mint Cinnamon/X11, test package behaviour, and resolve or replace illustrations whose redistribution rights are not yet established.

LINUX SOURCE & PREVIEWS ↗
02 / NATIVE WINDOWS EDITIONDEVELOPMENT ALPHA

ClipMint for Windows x64

Built as a separate Windows application with Qt/Python and bundled FFmpeg in one offline portable ZIP. Its GitHub build passed 32 automated tests and includes a self-signed Authenticode development signature and verified build provenance.

Before the coordinated launch: physical Windows desktop acceptance, a permanent release download and accurate warnings that the development certificate is not Microsoft-trusted. Windows clipboard history is stored locally in plaintext by default.

WINDOWS SOURCE & BUILD ↗

A shared name does not mean shared clipboard history, cloud storage, automatic migration, identical features or synchronised settings. These editions remain independent by design.
