# Contributing

ELF//SHELL is intended as a freely usable, modifiable, shareable community project. Corrections, icons, accessibility refinements and Firefox compatibility fixes are welcome.

1. Fork the public repository once published.
2. Make a small change and explain its purpose.
3. Run `npm test` before opening a pull request.
4. Do not add analytics, telemetry, hidden background requests, advertising, remote scripts, or invasive permissions.
5. Source images and icons locally. Respect third-party copyrights and trademarks. Keep new functionality optional when it requires additional permissions.

Please do not commit private session exports, customer information, passwords or tokens. For any issue reporting a security vulnerability, avoid posting private data publicly.

Please do not add remote RSS proxies, tracking pixels, remote article thumbnails, auto-subscriptions or non-opt-in host permissions. RSS content is untrusted XML; display only safe text and use DOM node creation rather than injecting feed HTML.
